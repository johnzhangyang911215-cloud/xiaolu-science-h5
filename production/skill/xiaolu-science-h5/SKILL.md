# 小鹿精华科普 H5 续作

先找含“从一只梅花鹿说起”、Science 封面、双舱使用和 28 天数据的工程。有同名作品时，比对镜头和交付记录。聚焦叙事版的源时间线在 `横版/assets/js/main.js`，`window.__timing.edition` 为 `focus`。交接于 2026-11-18 的基线为 2957 帧、1920×1080、30 fps。以后查最新版，按新交付的证据重新确认。

## 从任务找到修改入口

- 用成片做删减、重排、换声轨时，导入参考 MP4，对照交接包“七幕时间码.csv”。时间码以 0 为首帧，出点不含该帧。需要独立音乐时取 `assets/audio/bgm.mp3`。
- 改字幕、品牌或资料数字时，同时检查分文件 `index.html` 里的静态文字、`data-v` 和 `main.js` 里的动态标题、步骤字幕。改排版优先查看最后加载的 `assets/css/cinema.css`。新增汉字时检查子集字体的字形覆盖。
- 改镜头时从 `main.js` 的 `scenes` 定位幕次，对照 `cinema-layout.js`、`scene3d.js` 的空间和材质。按压和落粉同时受时间线、`usage-curves.js` 和模型部件名约束。替换模型先核对层级、节点和动画名。
- 供三维软件使用的模型可从交接包“片中实际GLB”取得。只有网页分片时，读取 `assets/models/manifest.js`，按每个模型的 files 顺序拼接回调的最后一个 Base64 参数，再整体解码。核对 GLB 文件头、版本 2 和文件长度。编辑网页仍需按原键名生成分片和清单。

## 镜头和内容基准

用上一幕的主体位置接下一幕。保证观众先看到主体，再看到动作，最后有时间读结果。鹿茸扫描维持部位对应；科研幕先封面后分支；冻结接粉仓，5 mg 冻干粉与 1.5 mL 溶媒分次出现；拉环、按压落粉、摇匀、掰开滴出逐步可辨。包装实拍与模型交接时对齐同一瓶肩、瓶底和盒边。改动后从前一幕开始连续看一次。

产品资料 PDF 第 38–39 页核对顶部蜡片和双舱规格，第 40 页核对四项 28 天结果。Science 封面用于交代反刍动物研究背景。尾屏沿用“韶初泌语”和原指标方向，具体数字从交接包资料或后续确认的产品文件读取。

## 重建和交接

在交接包工程副本中运行 `python3 tools/bundle.py 横版`；打包器从分文件工程内嵌字体、图片、配乐、脚本和模型。用 `node tools/export.cjs 横版 --check` 检查离线 WebGL、解码和 UI 隐藏。需要新版 MP4 时用同一命令去掉 `--check`，以 30 fps 逐帧推进并合入原速配乐。使用交接说明里的 Node、Playwright/Chromium 和 FFmpeg 配置。

核对导出报告的 sourceSha256 和 outputSha256，再由 scenes[].startFrame 和 frames 更新各幕入出点。交接设计修改时保留源工程、直接可用的设计素材、对应资料页、音乐、成片与预览。旧版字幕表和时长应在新时间线核对后再沿用。
