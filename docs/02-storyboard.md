# 小鹿精华 H5｜导演分镜

16:9 横版 1920×1080，跟音乐自动推进，全长 **104.23 秒**（正片到 99.99 秒，尾帧淡出到 104.23 秒）。上游资料见[任务 1 简报](01-brief.md)。新增手模、实拍时间码、备案和功效手卡见[分镜补充素材](02-asset-supplement.md)。

## 0　总则

### 0.1　一条主线：暖金光点

全片只有一个视觉焦点，它是一粒暖金光点，依次变成下列形态：

> 双阳地图落点 → 逆光的茸尖 → 蜡片 → 研究里被点亮的数据点 → 冻干粉 → 落进溶媒的粉末 → 滴在皮肤上的一滴精华

每一幕的第一眼都落在这粒光点上，转场就是镜头跟着它走。只要光点还在画面里，就不硬切。

### 0.2　光线从夜到晨

| 段落 | 底色 | 主光 | 情绪 |
|---|---|---|---|
| 幕 1–3 | 墨黑 #0A0B0D | 雪原白 #F2F1EC 冷月光 + 暖金点光 | 夜、雪、静 |
| 幕 4 | 墨黑 #0A0B0D | **科技蓝 #5FB8E6**（只在本幕使用） | 理性、精确 |
| 幕 5–7 | 墨黑渐亮到雾灰 #2A2C30 | 雪原白棚光，茸尖暖金 #C8A26A 点缀 | 器物、手作 |
| 幕 8 | 雪原白 #F2F1EC | 柔光 | 天亮 |

### 0.3　音乐与时钟

- 配乐用 `assets/audio/bgm.mp3`，约 112 BPM，一拍 0.534 秒，一小节（4/4）2.13 秒，**不剪辑、不变速**，从 0 秒起播。
- 以 `audio.currentTime` 作为主时钟，每幕在下表的入点触发。沿用 Codex 的做法：用分段速度表调整幕内动作快慢（[PACING L892](../reference/codex/assets/js/main.js#L892)），首次交互后启声（[bgm.js L14](../reference/codex/assets/js/bgm.js#L14)），淡入 1.2 秒、淡出 3.2 秒。不同的是，幕间切点改为锁在下表的音乐时间码上，不再由各幕时间轴结束时触发。
- 下表的时间码由 librosa 节拍与段落分析得出，导演按段落选点。实现阶段请对听复核，误差不超过 ±1 帧（30 fps）。

| 音乐结构 | 时间 | 特征 |
|---|---|---|
| 前奏 | 0.07–17.07 | 0.07 起音最强；3.25、7.50、9.64 为重击；11.24–12.31 几乎静音 |
| 主段 A | 17.07–77.65 | 17.07 全编制进入；31.95–33.55 有四拍加花，落在 34.09 |
| 间奏 | 77.65–93.60 | 77.65 重击后能量下沉；86.15 重击后，87.75–88.82 近乎静音 |
| 再现段 | 93.60– | 93.60 重拍回归；音乐到 132 秒才自然收尾，本片在 101.03 秒开始淡出 |

### 0.4　两个指定落点

| 落点 | 时间码 | 帧（30 fps） | 选它的理由 |
|---|---|---|---|
| **茸尖定格** | **34.09 s** | 1023 | 主段第一个八小节乐句的终点。31.95 起四拍加花把情绪推上去，34.09 是重低音落下的下拍（低频能量 0.83）。镜头推近过程中的情绪在这一刻收住。 |

### 幕 7　释 · 使用五步（77.65 → 99.99）

**第一眼**：每一步只看一个动作部位：安全环 → 尾盖 → 下落的粉末 → 瓶头断口 → 皮肤上的那一滴。
