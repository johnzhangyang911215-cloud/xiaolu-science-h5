# 分镜补充素材

本页对应 [104.23 秒导演分镜](02-storyboard.md)。以下时间码均为各实拍原片内的时间，制作时间线仍以导演分镜为准。

## 幕 7 · 用手操作安瓶

| 素材 | 如何使用 |
|---|---|
| [双手及手臂 GLB](../assets/models/runtime/FemaleArms-v3-Customizable.glb) | 已绑定骨骼，含 66 个形态键，皮肤与指甲贴图内嵌。可分别摆左右手，按实拍制作握持和指尖接触关键帧。文件不含预制使用动作。 |
| [实拍使用方法 2](../assets/reference/%E5%AE%9E%E6%8B%8D%E4%BD%BF%E7%94%A8%E6%96%B9%E6%B3%952.mp4) · 720×1280，30 fps，27.20 秒 | 优先对照手势。约 4.5 秒取支，6.5 秒撕开底部保护环，8.6 秒双手斜持并沿瓶轴按压，10.6 秒摇匀，13.6 秒打开瓶头，14.6–19 秒出液至掌心、双手推开，约 23 秒上脸。 |
| [实拍使用方法 1](../assets/reference/%E5%AE%9E%E6%8B%8D%E4%BD%BF%E7%94%A8%E6%96%B9%E6%B3%951.mp4) · 960×1280，30 fps，48.23 秒 | 讲解补充。约 8–18 秒为瓶身和双手近景，约 33–43 秒可参考开口、出液和手背示范。 |

以 86.15 秒为尾盖压到底的音乐落点。实拍 2 的按压姿态略向下倾斜，可看清一手稳定瓶身、另一手按尾盖。分镜中表现粉末入液的剖面可另选角度。实拍有掌心和面部涂用画面，指腹推开单滴、清晰可见肤纹的微距仍待补拍或三维制作。
