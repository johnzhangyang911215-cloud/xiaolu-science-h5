# 小鹿精华 H5 · 导演接手简报

**任务 2 从这里开始。** 成片为 16:9 横版。用户喜欢 Codex 聚焦版的音乐卡点、Grok 蓝色横版的鹿茸展示，希望观众先感到东北产地的空间尺度，再沿着一只鹿的茸尖看懂一支精华。下一份交付是 `docs/02-storyboard.md`，用于剪辑和后续网页实现。

## 两版各取什么

| 参考片 | 值得保留 | 新版要解决的问题 |
| --- | --- | --- |
| [Codex 聚焦版](../production/previews/focus/) · 1080p，98.57 秒，自动推进 | 从整鹿到茸尖、从冻干粉到按压落粉，都能跟随一个主体看完。字幕与动作按时间落位，适合作为配乐和产品动作底稿。 | 开篇很快从标题进入线框鹿，缺少地理纵深。双舱与使用从 44.73 秒延续至 82.00 秒，约占全片 38%。尾屏盒瓶与四项数字同时争夺注意力。 |
| [Grok 蓝色横版](../production/previews/grok/) · 有声预览 106.60 秒，网页默认点击切幕 | 鹿头推至鹿茸，四层标注跟着同一根茸移动，观众能把名称和位置对应起来。最值得借的是从整体找到蜡片的过程。 | 侧边小字和细引线在远处难读，部分段落更像翻页。点击切幕的时间因人而异，剪辑应按有声预览或固定时间轴对点。 |

**聚焦版看片定位（秒）。** 0.00 片头 → 3.80 整鹿 → 10.20 四季 → 19.77 鹿茸分层 → 36.27 研究 → 44.73 双舱及使用 → 82.00 盒瓶与功效。剪辑可按 30 fps 对齐原片。两版网页使用相同的配乐文件；这些秒数是旧片切幕点，新分镜的音乐重音仍需对听。[逐帧时间码](../production/storyboard/七幕时间码.csv) · [网页配乐](../focus/assets/audio/bgm.mp3)

## 可直接复用的代码与素材

| 制作环节 | 实现入口 | 怎样接入新分镜 |
| --- | --- | --- |
| 鹿 → 茸 → 蜡片 | [Grok 鹿茸镜头](../grok/assets/js/main.js#L275) · [四层标注](../grok/assets/js/main.js#L504) | `antCam()` 按鹿茸包围范围构图；`R3.antCLat(mi,h,o,0,1.05,0)` 取茸轴上的三维点，再由 `project(o[0],o[1],o[2])` 定位屏幕标签。保留三维跟踪，让标注随镜头走。 |
| 混合与滴用 | [聚焦版动作时间线](../focus/assets/js/main.js#L703) | `stepOn(0,15.0)` 在本幕第 15 秒激活拉环，紧接同秒字幕。按压、摇匀、掰开同样由本幕时间推动。重排时将动作和字幕一起移动。 |
| 功效数字与节奏 | [尾屏数字](../focus/assets/js/main.js#L806) · [分段播放速度](../focus/assets/js/main.js#L892) | `rollNum(tl,nums[i],nums[i].dataset.v,1.8,t+.15)` 让数字用 1.8 秒到达终值。按镜头需要错开盒瓶、指标名和最终读数，并留出静止阅读时间。 |

- **建模同事**可直接打开[四份网页用 GLB](../production/models/runtime/)（鹿、单支、使用动作、合盖盒）。另有[原始 GLB](../production/models/drive/)、[高精合盖盒](../production/models/high-detail/)和 [Blender 母版及材质脚本](../production/blender/)。
- **剪辑同事**可取[系列与包装原图](../production/product-images/)、[品牌标志](../production/brand/)、[手卡](../production/reference-cards/)、[音乐](../production/audio/)和[环境光](../production/lighting/)。[逐文件清单](../production/drive-inventory.csv)可按原名查到仓库实体。[制作说明](../production/README.md)含打包与导出方法。
- **开场待补素材**包括可用的地球至双阳多尺度地图、可核验拍摄地点的鹿场实拍。现有鹿模型足以设计预演；分镜须注明哪些镜头采用三维示意、哪些镜头需要补拍或取得素材。

## 给导演的交付要求

沿「地球 → 吉林长春双阳 → 梅花鹿与蜡片 → 研究及产品系列 → 单支精华 → 冻干与按压复溶 → 滴用及成品证据」写出可剪辑的分镜。每幕写清绝对入出点、音乐卡点、画面主体、镜头与缓动、上屏文案、下一幕怎样接、使用哪个文件或需补什么素材。把需要确认的产地表述单列。分镜交付后由用户审阅，再进入网页实现。
