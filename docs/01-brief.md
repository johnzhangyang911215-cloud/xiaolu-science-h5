# 小鹿精华 H5｜导演接手简报

导演方向：地球 → 吉林长春双阳 → 梅花鹿与茸尖 → 研究 → 系列与单支 → 复溶、滴用。用户确认后进入分镜。

## 1　两版看片笔记

**Codex 聚焦版**（98.57 秒，自动播放）。片头 → 整鹿 → 四季 → 分层 → 科研 → 双舱与使用 → 产品与功效。七幕入点依次为 0、3.80、10.20、19.77、36.27、44.73、82.00 秒。[原工程](../reference/codex/) · [30 fps 剪辑时间码](../assets/storyboard/七幕时间码.csv)

| | 看片依据 |
|---|---|
| 优点 1 | 19.77 秒沿上一幕的茸尖亮点推进，四季自然接入分层。 |
| 优点 2 | 分层先快后慢，蜡片落定时留足读字时间。 |
| 优点 3 | 拉环、落粉、摇匀、滴用逐项对齐字幕，便于复剪。 |
| 缺点 1 | 片头标题直接接线框鹿，缺少地理铺垫。 |
| 缺点 2 | 双舱与使用占 44.73–82.00 秒，约 38%，挤压了系列亮相。 |
| 缺点 3 | 82 秒后盒瓶与四项数字同屏，阅读先后不清。 |

**Grok 蓝色横版**（有声预览 106.60 秒）。整鹿与四季 → 茸尖 → 研究 → 双舱 → 产品。粒子变形与推进镜头接幕；音乐连续，默认点击切幕。[原工程](../reference/grok/) · [切幕逻辑 L681](../reference/grok/assets/js/main.js#L681)

| | 看片依据 |
|---|---|
| 优点 1 | 镜头从鹿头推近鹿茸，容易定位茸尖。 |
| 优点 2 | 骨片、血片、粉片、蜡片的引线随茸轴移动；定格仍能辨认取材部位。 |
| 优点 3 | 蜡片从原位移出，可承接下一幕科研封面。 |
| 缺点 1 | 分层侧标小、引线细，手机横屏难读。 |
| 缺点 2 | 科研封面、分支图和说明同时出现，焦点分散。 |
| 缺点 3 | 手动停幕会错过原曲重音，切点不可复现。 |

## 2　可复用实现

- **音乐**。Codex 的 `PACING` 依次设 1.05、0.95、0.9 倍速，`timeScale` 在指定时间切换。导出器按原速铺音乐，淡入 1.2 秒、淡出 3.2 秒；网页另有首次交互启声逻辑。按原曲对听重音，手工定切点。[速度表 L892](../reference/codex/assets/js/main.js#L892) · [应用 L919](../reference/codex/assets/js/main.js#L919) · [网页启声 L14](../reference/codex/assets/js/bgm.js#L14) · [导出混音 L129](../tools/export_focus.cjs#L129)
- **鹿茸**。Grok 的 `antCam()` 按茸高取景；`antCLat()` 取茸轴三维坐标，`project()` 投影后放置标注。换镜头时沿用茸轴锚点。[取景 L276](../reference/grok/assets/js/main.js#L276) · [跟踪 L504](../reference/grok/assets/js/main.js#L504)

## 4　宣称与禁用表述

抗皱、紧致和量化数据须核对成品功效评价摘要。p40 未列样本量，勿移用 p43 的人数或面膜 PDF 的测试值。禁用「治疗皱纹」「让皮肤细胞再生」等医疗暗示；「100%吸收」「零刺激」「仅占鹿茸总量2%」缺少对应证据。双阳可作创意地理落点，供应基地待核。[规范第九条与条例原文](../assets/README.md#功效宣称依据)
