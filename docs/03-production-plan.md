# 小鹿精华 H5｜制作计划（交给 Sonnet 执行）

依据：[导演分镜](02-storyboard.md)（`ee4c4fa`）与[分镜补充素材](02-asset-supplement.md)。分镜决定**看什么、何时看**，本计划决定**用什么做、怎么验收**。两者冲突时以分镜的时间码为准，并在会话结束时报告冲突。

## 0　执行规则

1. **新建目录 `film/`**，不改 `focus/`、`grok/`、`reference/`。需要的代码从 `reference/` 复制进 `film/` 再改，并在文件头注明来源路径。根目录 `index.html` 只加一个入口链接。
2. **文案不自己写**。所有上屏文字集中在 `film/copy.json`，每条带 `scene`、`in`、`out`、`text`、`source`（PDF 页码、KT 板编号或“分镜”）。分镜里没有的文字不上屏。标为待核的文字用 `"status":"pending"`，默认不渲染。
3. **时间码只写在一处**。`film/assets/js/cues.js` 定义全部音乐时间码（见第 2 节）。动画代码只引用 cue 名，不写裸秒数。
4. **每个会话只做本计划第 4 节列出的那一段**。结束时提交代码，附验收截图和 `__cues` 检查输出，并列出偏离分镜之处。
5. 资源和链接用相对路径，保证 GitHub Pages 子路径能加载。

## 1　技术骨架（会话 S0）

| 模块 | 做法 | 来源 |
|---|---|---|
| 主时钟 | `<audio src="bgm.mp3">` 的 `currentTime` 是唯一时钟。每帧读取一次，传给所有幕的 `render(t)`。**不使用** GSAP 的全局时间轴来推进幕间切换。 | 新写 |
| 幕调度 | `scenes[]`，每项含 `in`、`out`、`preload()`、`enter()`、`render(t, local)`、`exit()`。当前 t 落在哪一幕就渲染哪一幕；相邻幕的交接段允许两幕同时渲染。 | 新写 |
| 幕内动画 | 每幕用一条**暂停的** GSAP 时间轴，在 `render` 里调用 `tl.seek(local)`。这样任意时刻都能精确复现，拖动、导出都不跑偏。 | Codex `PACING` 的分段变速改写成时间轴内的 ease 和时长，不再改 `globalTimeline.timeScale` |
| 三维 | Three.js 单一 renderer、单一相机对象，各幕切换相机轨道。 | `reference/codex/assets/js/three.bundle.min.js`、`scene3d.js` |
| 启声 | 首次点击启声，点击前显示静帧加“轻触开始”。 | `reference/codex/assets/js/bgm.js` |
| 调试接口 | `?t=34.09` 直接跳到指定时间并暂停；`window.__seek(t)`、`window.__scene()`、`window.__cues()`（输出每个 cue 的实测状态，见第 3 节）。 | 新写 |
| 导出 | 从 `tools/export_focus.cjs` 复制出 `tools/export_film.cjs`：逐帧 `__seek(frame/30)` 截图，按 30 fps 合成 MP4，音乐原速铺入。 | `tools/export_focus.cjs` |
| 加载 | 首屏只加载幕 1–2 的资源；其余幕在前一幕播放时预加载。总包体目标 ≤ 30 MB，单个模型 ≤ 4 MB。 | 新写 |

**S0 完成标准**：8 个占位幕（纯色底 + 幕名 + 当前时间）随音乐准确切换；`?t=` 跳转正确；导出得到一段 104.23 秒的占位 MP4，切点与第 2 节相差不超过 1 帧。

## 3　音乐落点验收

每个关键 cue 在 `__cues()` 中输出一项可量化的状态。验收脚本 `tools/check_cues.cjs` 用 Playwright 逐个 `__seek` 到 cue 前后各 1 帧，读取状态并截图，存到 `film/qa/`。

| cue | 前 1 帧 | 当帧 | 后 1 帧 |
|---|---|---|---|
| `antlerFreeze` | 相机速度 > 0 | 相机速度 = 0，茸尖高度占画面 55–65% | 相机速度 = 0，雪花仍在下落 |
| `pressBottom` | 尾盖行程 0.85–0.99 | 尾盖行程 = 1.00，隔膜状态为打开 | 粉末开始下落（y 方向位移 > 0） |
| `powderHit` | 粉末尚未接触液面 | 粉末接触液面 | 开始晕开 |
| `ringOff` / `snap` | 部件仍连接 | 部件分离 | 部件分离 |
| 各幕入点 | — | `__scene()` 等于本幕 | — |

此外还有两项人工验收：
- **看片**：导出 MP4 后，在 34.09 秒和 86.15 秒前后各看 2 秒，动作必须“砸”在重音上，不能抢拍或拖拍。
- **第一眼**：每幕入点后 0.5 秒截一张图，把画面缩成 32×18 的小图，最亮或最暖的格子必须落在分镜“第一眼”写的对象上。

## 4　分幕制作

格式：**素材** / **关键动作做法** / **本幕验收**。路径相对仓库根目录。

### 幕 1　地球到双阳（0.07–17.07）· 会话 S1

**素材**
- 地球贴图：NASA Blue Marble（日面）+ Black Marble（夜面城市灯光），2048 px 版本，放在 `film/assets/earth/`，并附 `SOURCE.md` 写明出处和公有领域声明。如果沙箱无法下载，用程序生成的海陆着色器替代，并在提交中报告。
- 东北亚地形：程序化高度图（多层噪声 + 长白山脉方向的脊线），叠雪原着色。
- 省界、纬线、地名：手绘矢量 SVG，位置按经纬度换算。双阳约为 125.67°E、43.52°N。

**关键动作做法**
- 地球是一个球体，用日夜混合着色器，晨昏线由一个光照方向向量决定。
- 三级推进：在 `push1`–`push3` 处，相机距离分别按 ease `expo.out` 缩到上一级的约 1/3。每次推进 0.8 秒内完成，然后缓慢漂移。
- 从球面到地形：在 `push2` 和 `push3` 之间交叉淡入，地形平面贴着球面的切面出现。
- 穿云：`cloud` 到 `shuangyang` 之间用一层全屏噪声云，只保留暖金光点不被遮住。
- 双阳标注：在 `shuangyang` 处，标注线从光点向右上方画出，0.4 秒画完，再淡入地名。

**本幕验收**：`shuangyang` 当帧光点在画面中心 ±5% 以内；全幕字幕只有 copy.json 的三条，没有“基地”“产地”字样。

### 幕 2　鹿头到茸尖（17.07–34.09）· 会话 S2

**素材**：`assets/models/runtime/deer.glb`。模型自带 7 段动作：`Walk_forward_RM_Skeleton`、`Idle_1–3_Skeleton`、`eat_1_Skeleton`、`drink_Skeleton`、`Rotate_left90_RM_Skeleton`，**没有现成的“停步”和“抬头”**。做法：`s2`→`deerStop` 播 `Walk_forward`（根运动），`deerStop` 用 0.5 秒交叉淡入到 `Idle_1`；`deerStop`→`deerLook` 保持 `Idle_1`，同时程序化旋转颈部和头部骨骼完成抬头，在 `deerLook` 当帧到位（不倒放其他动作）。如需更精细的茸尖，可在定格前 2 秒切到 `assets/models/drive/梅花鹿_鹿茸合成.glb`（47 MB，须先用 gltf-transform 压到 ≤ 4 MB，或只截取茸部网格）。雪、白桦林剪影、月光都由程序生成。

**关键动作做法**
- 推进相机：复制 Grok 的 `antCam()`（`reference/grok/assets/js/main.js` 第 276 行），以茸高取景。相机路径为“鹿头 → 茸根 → 茸尖”的样条，进度 p 从 `deerLook` 的 0 推到 `antlerFreeze` 的 1。
- 逐拍加速：`fillStart` 到 `antlerFreeze` 之间分 4 段，每拍推进量依次为 10%、15%、20%、25%（整段相机路径的比例）；最后一拍使用 `power3.in`，**在 `antlerFreeze` 当帧速度归零**（用一个 0.03 秒的硬停，不做回弹）。
- 定格：只停相机和鹿的动作；雪粒子继续以 30% 速度下落；茸尖绒毛的边缘光在定格后 0.5 秒内轻微增亮。
- 景深：用后期处理的 bokeh，焦点始终锁在茸尖。

**本幕验收**：见第 3 节 `antlerFreeze`；茸尖是全画面最暖的区域。

### 幕 3　蜡片的位置（34.09–44.72）· 会话 S2

**素材**：幕 2 的茸部模型；分层位置对照 `assets/reference-cards/小鹿KT（电商）/KT板44.jpg`（从下到上依次为骨片、血片、粉片、蜡片）；剖面贴图用着色器生成分层渐变，不使用手卡原图。

**关键动作做法**
- 茸体半透明化：给茸部材质加一个 `reveal` 参数，从 0 到 1 时外表面透明度降到 0.25，内部分层体显现。
- 标注跟随：复制 Grok 的 `antCLat()` 和 `project()`（`reference/grok/assets/js/main.js` 第 504 行），每层取茸轴上的一个锚点，每帧投影到屏幕，引线贴着锚点。字号不小于 28 px，引线 2 px。
- 逐层点亮：本层亮度 1.0，已亮的层降到 0.35，未亮的层为 0.15。
- 蜡片上浮：`wax` 后，蜡片网格沿茸轴方向平移 1.2 个茸径，同时放大到画面中心，进入幕 4。

**本幕验收**：文字“顶端 2% 处”必须出现，“仅占 2%”不得出现；手机横屏（844×390）截图上标注字仍清晰可读。

### 幕 4　对应研究（44.72–59.58）· 会话 S3

**素材**：粒子系统沿用 Grok `reference/grok/assets/js/particles.js` 的思路，重写为 Three.js `Points` 加自定义着色器；文献卡、峰图用 HTML/SVG 叠加层实现。

**关键动作做法**
- 成分环：约 6000 个粒子从蜡片位置散开，排成环形；6 个成分名按 0.7 秒间隔依次点亮。
- 分支和螺旋：`ref1` 时粒子目标位置切换为分支曲线（复用 Codex 的 `s4-points.js` 分支点集），`ref2` 时切换为双螺旋，用 `power2.inOut` 补间 1.6 秒。
- 文献卡：同一时间只显示一张，从右侧滑入 0.5 秒，卡片只写作者、期刊、年份、研究对象。
- 收拢：`converge` 时所有粒子向中心收缩，颜色从 #5FB8E6 插值到 #C8A26A。

**本幕验收**：只有本幕出现 #5FB8E6；p7、p12 的文案在复核前标为 `pending`，渲染为空卡（见第 5 节）。

### 幕 5　系列与单支（59.58–68.10）· 会话 S4

**素材**：系列图选 `assets/product-images/全家福3.png`（2180×1096，横幅，最适合 16:9；若构图不符，改用 `全家福4.png` 裁切）；包装和名称核对 KT6–KT9、KT18（见补充页表）；单支 `assets/models/runtime/ampoule.glb`；棚光 `assets/lighting/studio_small_03_1k.hdr`。

**关键动作做法**
- 系列全景用 2.5D：把产品图按产品抠成 3–5 层，放在不同深度做视差横移。抠图另存为 `film/assets/family/*.webp`。
- 压暗其他产品：除精华外，其他层亮度从 1 降到 0.3。
- 单支前推：在 `single` 时，从 2D 图层交叉淡入到 3D 安瓶，两者的位置和角度必须对齐（先截一张 3D 渲染图，与产品图叠加核对）。

**文案**：品名用 **韶初泌语鹿茸凝时抗皱冻干精华液**（KT 板 19 备案截图），一行排不下时，在“鹿茸凝时”后换行。

**本幕验收**：品名逐字与 KT 板 19 一致；交叉淡入时安瓶轮廓位移不超过 4 px。

### 幕 6　−40℃ 双仓（68.10–77.65）· 会话 S4

**素材**：`assets/models/runtime/usage.glb`（使用其中的 `GEO_PowderCup_PROXY`、`PowderCloud_14400`、`FineGrainShared`、`PorousFlakeShared`、`GEO_Body_Refined`）；霜冻特效复制 `reference/codex/assets/js/frozen-chamber.js`；剖面结构对照 `assets/pdf/pages/serum-38.jpg`、`serum-39.jpg`。

**关键动作做法**
- 剖切：用 Three.js 的 `clippingPlanes`，剖切平面在 `s6` 之后 0.8 秒内扫过整支安瓶。剖面做一个盖面，避免露出模型内部空洞。
- 温度：数字从 20 滚到 −40，用 `XCond` 字体，与霜花蔓延同步。
- 标注：冻干仓、溶媒仓各一条引线，跟随模型锚点投影（同幕 3 的做法）。
- 合拢与转向：在 `close` 时剖切平面退回，安瓶转为幕 7 起始的斜持角度（不是尾部朝上，见幕 7）。

**本幕验收**：上屏数字仅有 −40℃、5 mg、1.5 mL，并与 p38、p39 一致；字幕用“锁鲜”，不用“锁活”。

### 幕 7　使用五步（77.65–99.99）· 会话 S5（最重的一段）

**素材**
- 双手：`assets/models/runtime/FemaleArms-v3-Customizable.glb`（10.8 MB，带骨骼，不含动作）。先用 `npx @gltf-transform/cli optimize --compress meshopt --texture-compress webp` 压到 ≤ 4 MB，输出到 `film/assets/models/arms.glb`。会用到的骨骼：`DEF-hand.L/R`、`DEF-forearm.L/R`、`DEF-thumb.01–03.L/R`、`DEF-f_index.01–03.L/R`、`DEF-f_middle.01–03.L/R`；无名指和小指跟随中指。
- 安瓶部件：`usage.glb` 中的 `GEO_SafetyRing`、`Ring_rib_00–03`（安全环）、`GEO_BodyTailRim`、`TailLipMesh`（尾盖）、`GEO_HeadSeal_Refined`、`GEO_NeckRim`（瓶头）、`FX_FallingSerumJet`（出液）、粉末三件。动作曲线参考 `reference/codex/assets/js/usage-curves.js`。
- 手势参考：`assets/reference/实拍使用方法2.mp4`。

**实拍与成片对位**（实拍时间码来自补充页，已核对）

| 动作 | 实拍 2 | 成片 cue | 手势要点 |
|---|---|---|---|
| 撕环 | ≈ 6.5 s | `ringGrip` 78.72 → `ringOff` 81.90 | 一手握瓶身，另一手拇指与食指捏住底部保护环，向外撕开 |
| 换手、斜持 | 6.5 → 8.6 s（约 2.1 s） | `ringOff` 81.90 → `pressContact` 84.03（2.13 s） | 双手斜持安瓶，瓶身略向下倾；一手稳住瓶身，另一手拇指移到尾盖 |
| 沿瓶轴按压 | ≈ 8.6 s | `pressContact` 84.03 → **`pressBottom` 86.15** | 拇指沿瓶轴方向压下。行程曲线：前 70% 用 1.6 秒匀速，后 30% 用 0.5 秒 `power4.in` 加速到底，**86.15 当帧到底** |
| 摇匀 | ≈ 10.6 s | `shake1–3` 89.35 / 90.42 / 91.49 | 腕部左右摆动三次，幅度 ±12° |
| 打开瓶头 | ≈ 13.6 s | `snap` 93.60 | 拇指与食指掰开瓶头 |
| 出液、推开 | 14.6–19 s | `snap` → `dropLand` 95.71 → 99.99 | 见下方“出液与涂抹” |

**关键动作做法**
- **手部动画**：在代码里为每个 cue 设定一组骨骼旋转的关键姿势（约 8 个姿势：握持、捏环、撕环、斜持、拇指就位、压到底、摇匀、掰开），姿势之间用四元数插值。做姿势时把实拍对应帧作为半透明叠层参考，并留一个调试开关 `?ref=1` 显示叠层。
- **指尖接触**：按压阶段，每帧把拇指末节 `DEF-thumb.03` 的位置约束到尾盖中心（简单的 IK：先转手腕对准，再分配到拇指三节）。尾盖位移量与拇指位移量完全一致，杜绝穿模或悬空。
- **按压到落粉的镜头交接**：实拍的斜持角度看不清粉末下落，因此在 `pressBottom` 当帧，以按压的“咔”作为剪辑点，**匹配剪辑**到剖面特写。剖面特写里安瓶尾部抬高，粉末因此能看得清是在下落（补充页允许“剖面可另选角度”）。双手在剖面特写中虚化为前景轮廓。这是全片唯一一次硬切，切点必须落在 `pressBottom` 帧。
- **粉末下落**：`pressBottom` → `powderHit` 共 3.2 秒，粉末用 `PowderCloud_14400` 粒子，速度先慢后快（模拟慢动作逐渐恢复）；`powderHit` 时触液晕开，暖金色向下扩散。
